## ⚙️ Final setup checklist

**Banner:** upload `dark.svg` + `light.svg` to repo root and keep the `<picture>` block above.

**Stats:** fork `anuraghazra/github-readme-stats` → Vercel Hobby → Environment Variable `PAT_1` = your classic GitHub token → deploy → put your Vercel URL into the two commented cards above. Never share the token.

**Snake:** repo **Settings → Actions → General → Workflow permissions → Read and write permissions → Save**. Then commit `.github/workflows/snake.yml` to `main` and run **Actions → Generate Snake Animation → Run workflow**. Wait for green before expecting the `output` branch image.

**Source truth:** keep `generate_banner.py` + `portrait_points.npy` with the SVGs.
